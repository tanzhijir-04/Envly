# Envly

一键开发环境配置桌面工具（Windows → macOS → Linux）

One-click developer environment setup tool (Windows → macOS → Linux)

- 单页向导：选模板 → 勾选清单 → 一键配置 → 验证报告 / Single-page wizard: template → checklist → one-click setup → report
- 中英双语 / Bilingual (zh-CN / en)
- 网络区域自适应：大陆外不强制切换镜像 / Region-aware mirrors: skipped outside mainland China
- Pake 壳 + Go 引擎 / Pake shell + Go engine

See [design doc](docs/superpowers/specs/2026-08-16-envly-design.md).
